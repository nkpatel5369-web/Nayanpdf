## 6. Tests not run, and why

| Test | Status | Reason / what is needed |
|---|---|---|
| Installation under a standard (non-administrator) Windows account | Not run | CI runners use an administrator account. The installer is per-user and does not request elevation |
| Windows 10 and Windows 11 desktop editions | Not run | CI uses Windows Server 2025 (same kernel family as Windows 11) |
| Interactive (non-silent) installer pages: folder choice, desktop-shortcut option | Not run | Automated install is silent |
| Signing with a USB token / smart card (PKCS#11) | Not run | No hardware token available |
| Printing to a physical printer | Not run | No printer. The print job (sheets, page placement, black and white) is checked by sending the exact page the printer would receive to PDF instead (UI scenario 27); the engine tests cover page rendering, the print permission and the comments/forms options. Driver behaviour (duplex, tray, colour) depends on the printer and is not tested |
| High-DPI displays and Windows display scaling | Not run | Needs a physical Windows desktop |
| Dropping files from Explorer | Not run | Cannot be automated with the test driver |
| OCR accuracy for Hindi and Gujarati | Not run | Only English accuracy is asserted; the languages are installed and detected on Windows |
| Large-scale performance (hundreds of scanned pages, very large image-heavy files) | Not run | No benchmark was performed; only the 300-page open test |
| Keyboard shortcuts not covered by scenarios 2, 29 and 33 (Read Out Loud keys, Ctrl+Q included): Ctrl+A (checked by hand on Linux), Ctrl+Tab / Ctrl+Shift+Tab, Ctrl+F4, Ctrl+K, PageUp/PageDown in single-page layouts; batch cancel and retry; folder scanning; disk-full and access-denied handling | Not run | Implemented; not covered by automated tests |
| Scanning with a physical scanner (flatbed and document feeder) | Not run | No scanner in CI. Covered: the no-scanner message on Windows, and the full flow with a simulated scanner in a development build |
| Read Out Loud producing audible speech | Not run | CI machines have no sound device; the app's handling of that case is tested |
| Prepare a form detection on real client forms | Not run, by design | Synthetic forms only; detection is rule-based and its suggestions are reviewed by the user |
| Upgrade from NayanPDF with data the app wrote itself | Partly | Build 19 upgraded a real NayanPDF 1.0 installation and carried over a planted settings file; saved signatures encrypted by a real NayanPDF session were not part of the test |
| Real-world documents | Not run, by design | The brief requires synthetic test documents |
