All test documents are synthetic and generated by the test suite (`engine/tests/conftest.py`): numbered multi-page PDFs, a 300-page report, a profit-and-loss statement and a bank statement whose table runs across pages (produced through LibreOffice so it has real embedded subset fonts), Indian identifiers (PAN, GSTIN, IFSC, account numbers), a scanned page, an image-heavy file, an interactive form with text, check box, drop-down and radio fields, encrypted and permission-restricted files, and malformed, truncated and non-PDF files. No client document was used.

## 5. Defects found by testing and fixed

| # | Defect | Found by | Fix |
|---|---|---|---|
| 1 | PDF to Excel: an account number wrapped inside its cell came out as "00098765432 1" | Engine test, bank statement | Cells rebuilt from individual characters, honouring the spacing at line wraps |
| 2 | PDF to Excel: a bank transaction split by a page break became two rows | Engine test | Continuation rows stitched across pages |
| 3 | Editing text set in a standard (non-embedded) font failed verification | Engine test | Standard font metrics added |
| 4 | Redaction pattern search missed identifiers wrapped across lines | Engine test (verification refused to save) | Second search pass over joined lines |
| 5 | A PAN embedded inside a GSTIN was not redacted | UI test | Pattern corrected; verification now names the remaining items |
| 6 | Text-box comments with a border colour could not be created | Engine test | Rich-text annotation used when a border is set |
| 7 | The owner password did not lift restrictions on files with no open password | Engine test | Authentication corrected |
| 8 | Signature verification crashed on a damaged file | Engine test (tamper case) | Reported as damaged |
| 9 | Zoom drifted after switching modes | UI test | Re-fit on layout change |
| 10 | PDF comment icons were missing in the viewer | UI test screenshots | Icons bundled locally |
| 11 | Replacing or deleting an image left the old picture's data inside the file; replacements were stretched | New engine test | Image removed from the page's resources; replacement fitted without distortion |
| 12 | LibreOffice fetched images linked by URL inside Word files during conversion (a privacy leak) | Offline review, confirmed by test | Every LibreOffice profile hardened; test added (fails without the fix) |
| 13 | Merge/Create file lists could drop newly added files when the window was busy (intermittent: the list was rebuilt from stale state after the thumbnail probe returned) | UI test, scenario 15 | List updates made atomic |
| 14 | Watermark dialog overflowed its window | UI test screenshot | Layout corrected |
| 15 | After deleting pages, a thumbnail asked for a page that no longer existed (uncaught error) | UI test console capture | Guarded |
