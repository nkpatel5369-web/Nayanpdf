No client document was used.

## 5. Defects found by testing and fixed

| # | Defect | Found by | Fix |
|---|---|---|---|
| 1 | PDF to Excel: an account number wrapped inside its cell came out as "00098765432 1" | Engine test, bank statement | Cells rebuilt from individual characters, honouring the spacing at line wraps |
| 2 | PDF to Excel: a bank transaction split by a page break became two rows | Engine test | Continuation rows stitched across pages |
| 3 | Editing text set in a standard (non-embedded) font failed verification | Engine test | Standard font metrics added |
| 4 | Redaction pattern search missed identifiers wrapped across lines | Engine test (verification refused to save) | Second search pass over joined lines |
| 5 | A PAN embedded inside a GSTIN was not redacted | UI test | Pattern corrected; verification now names the remaining items |
| 6 | Text-box comments with a border colour could not be created | Engine test | Rich-text annotation used when a border is set |
| 7 | The owner password did not lift restrictions on files with no open password | Engine test | Authentication corrected |
| 8 | Signature verification crashed on a damaged file | Engine test (tamper case) | Reported as damaged |
| 9 | Zoom drifted after switching modes | UI test | Re-fit on layout change |
| 10 | PDF comment icons were missing in the viewer | UI test screenshots | Icons bundled locally |
| 11 | Replacing or deleting an image left the old picture's data inside the file; replacements were stretched | New engine test | Image removed from the page's resources; replacement fitted without distortion |
| 12 | LibreOffice fetched images linked by URL inside Word files during conversion (a privacy leak) | Offline review, confirmed by test | Every LibreOffice profile hardened; test added (fails without the fix) |
| 13 | Merge/Create file lists could drop newly added files when the window was busy (intermittent: the list was rebuilt from stale state after the thumbnail probe returned) | UI test, scenario 15 | List updates made atomic |
| 14 | Watermark dialog overflowed its window | UI test screenshot | Layout corrected |
| 15 | After deleting pages, a thumbnail asked for a page that no longer existed (uncaught error) | UI test console capture | Guarded |
| 16 | **Windows: every edit, comment and redaction was refused** ("may not write to …\\Temp\\NayanPDF") when the Windows temp path contains short 8.3 names, which is common for user names that are long or contain spaces | UI test on Windows | Path checks expand the existing part of a path and re-append the rest; reproduced and verified on Linux with a symbolic-link temp folder; the installed-app self-check now performs an edit |
| 17 | **Windows: OCR produced no text but reported success**: Tesseract output formats were requested through optional config files that the bundle does not ship | Engine tests on Windows | Formats requested as parameters; OCR now fails loudly if Tesseract writes nothing; regression test with a minimal language folder |
| 18 | Main window larger than small screens (fixed 1440×920) | Windows CI desktop at 1024×768 | Window sized to the screen and maximised when it does not fit |
| 19 | Build: publisher-signature check failed on GitHub's Windows runners (Windows PowerShell module path) | Windows CI | Uses PowerShell 7 where available; reports PowerShell's own error |
| 20 | UI test could not start Electron on a fresh machine (Electron 43 downloads its binary on first use); the Organize scenario could pass without the change reaching the document | Windows CI | Test resolves Electron through its package; Organize now checks the document's page count |

## 6. Tests not run, and why

| Test | Status | Reason / what is needed |
|---|---|---|
| Installation under a standard (non-administrator) Windows account | Not run | CI runners use an administrator account. The installer is per-user and does not request elevation |
| Windows 10 and Windows 11 desktop editions | Not run | CI uses Windows Server 2025 (same kernel family as Windows 11) |
| Interactive (non-silent) installer pages: folder choice, desktop-shortcut option | Not run | Automated install is silent |
| Signing with a USB token / smart card (PKCS#11) | Not run | No hardware token available |
| Printing to a physical printer | Not run | No printer; print preparation (page rendering, permission check) is tested |
| High-DPI displays and Windows display scaling | Not run | Needs a physical Windows desktop |
| Dropping files from Explorer | Not run | Cannot be automated with the test driver |
| OCR accuracy for Hindi and Gujarati | Not run | Only English accuracy is asserted; the languages are installed and detected on Windows |
| Large-scale performance (hundreds of scanned pages, very large image-heavy files) | Not run | No benchmark was performed; only the 300-page open test |
| Keyboard shortcuts other than Ctrl+F; batch cancel and retry; folder scanning; disk-full and access-denied handling | Not run | Implemented; not covered by automated tests |
| Real-world documents | Not run, by design | The brief requires synthetic test documents |
