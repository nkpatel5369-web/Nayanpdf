# NayanPDF dependency and licence register

Every component that ships inside `NayanPDF_Setup.exe`, what it does, its licence, the conditions that apply to distribution, and its offline behaviour. Exact versions and SHA-256 hashes of every downloaded artefact for a given build are recorded in `resources/MANIFEST.json` inside the installation (generated by `scripts/build_runtime_win.py`).

## Licensing position of NayanPDF itself

NayanPDF is distributed under the **GNU Affero General Public License v3 (AGPL-3.0-or-later)**. This is a deliberate choice: the two strongest offline PDF engines available without a paid licence, MuPDF (via PyMuPDF) and Ghostscript, are dual-licensed AGPL-3.0 / commercial. Releasing NayanPDF itself under the AGPL, with its full source code, satisfies their conditions without buying a commercial licence. For personal use nothing further is required. If you ever distribute NayanPDF to others, or offer it to users over a network, you must make the corresponding source code available to them under the same licence (this repository satisfies that).

## Build-time only (not shipped)

TypeScript, Vite, esbuild, electron-builder (MIT), pytest and reportlab (test fixtures), pefile (DLL dependency analysis), micromamba (conda-forge package resolution). These are used to build and test NayanPDF and are not part of the installed application.

## Components evaluated and not used

| Candidate | Reason |
|---|---|
| Commercial PDF SDKs (Adobe PDF Library, Apryse/PDFTron, Foxit, Aspose) | Paid licences / activation; excluded by the brief |
| pymupdf4llm / pymupdf-layout | Pulls in onnxruntime and a machine-learning layout model (~70 MB) for a feature (Markdown export) implemented directly instead |
| Poppler utilities | GPL-2.0-only, overlaps with MuPDF |
| SumatraPDF for printing | Would add another GPL executable; printing is implemented with the bundled renderer and the Windows print dialog |
| veraPDF (PDF/A validation) | Requires a Java runtime (~150 MB); PDF/A output is checked with basic pre-flight checks and labelled as not formally validated |
| Online OCR / conversion services | Violate the offline requirement |
